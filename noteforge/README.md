# NoteForge — редактор фортепианных партитур

Настольное приложение для Windows (Electron + TypeScript + React) для сочинения, редактирования,
воспроизведения и печати нотных партитур. Гравировка — [Verovio](https://www.verovio.org)
(WebAssembly), звук — собственный SoundFont-синтезатор на Web Audio со встроенным банком
GeneralUser GS. Всё работает локально, интернет не нужен.

Реализованы все пять этапов исходного плана. Ниже точно указано, что проверено и какие есть ограничения.

## Требования

* Node.js 20+ (проверено на 22) и npm
* Windows 10/11 x64 для установленной программы (разработка возможна на Linux/macOS)

## Команды

```bash
npm install      # зависимости
npm run dev      # режим разработки (Vite + Electron)
npm run build    # проверка типов + сборка интерфейса (dist/) и main/preload (dist-electron/)
npm run dist     # build + установщик Windows: release/NoteForge-Setup-<версия>.exe
npm test         # модульные тесты (vitest)
npm start        # запуск собранного приложения
```

На Windows `npm run dist` не требует ничего дополнительного. При сборке Windows-установщика на Linux
electron-builder нужен Wine (32- и 64-битный: пакеты `wine64` и `wine32:i386`).
Установщик не подписан цифровой подписью — Windows SmartScreen может показать предупреждение.

## Возможности

### Нотный лист и интерфейс
* Тёмный интерфейс: меню (Файл, Правка, Вид, Вставка, Формат, Мелодия, Воспроизведение, Инструменты, Справка),
  панель инструментов, палитра символов, навигатор, панель воспроизведения, строка состояния, экранная клавиатура.
* Настоящие страницы A4/A3/Letter, книжная/альбомная, постраничный вид и «Лента», масштаб 25–400 %.
* Виртуализация: рисуются только страницы рядом с видимой областью; сотни страниц.

### Редактирование
* Ноты и паузы от целой до 1/64, точки, все знаки альтерации, аккорды, 4 голоса на стан.
* Ключи (скрипичный, басовый, альтовый, теноровый, 8vb) — в начале и с любого такта.
* Размеры любые (2/4…12/8, C, ¢, произвольные) со сменой и автоматической перегруппировкой; тональности.
* Лиги-связки (автоматически через тактовую черту), фразировочные лиги (в т. ч. между руками),
  автоматические и ручные рёбра, направление штилей.
* Ритмические группы: дуоли, триоли, квартоли, квинтоли, секстоли, септоли, произвольные n:m.
* Форшлаги (короткие и долгие), трель, морденты, группетто, фермата, стаккато, стаккатиссимо, тенуто, акцент, маркато.
* Динамика ppp…fff, sf, sfz, fp, rfz; вилки crescendo/diminuendo; педаль; 8va/8vb/15ma/15mb.
* Повторы, вольты (в т. ч. «1, 2.» и повтор n раз), сеньо, кода, To Coda, Fine, D.C., D.S. (al Fine / al Coda),
  двойная и заключительная тактовые черты, смена темпа внутри произведения.
* Такты: добавление, вставка, удаление; копирование/вырезание/вставка фрагментов; транспонирование по интервалу
  (с правильным написанием и сменой ключевых знаков).
* Отмена/повтор до 500 шагов.

### Мелодия, передаваемая между руками
* Мелодическая линия — свойство самих нот в модели: в неё можно включать ноты любого голоса любого стана.
* Межстановая запись (Ctrl+Shift+↑/↓): нота остаётся в своей руке и голосе, но рисуется на другом стане;
  рёбра и лиги через станы рисуются нативно.
* Линии подсвечиваются цветом, их ноты соединяются на листе; можно слушать отдельно мелодию или сопровождение.
* Пример из задания (C5 → B4 правой рукой, A4 → G4 левой) вводится и звучит как одна фраза.

### Воспроизведение
* Play/Pause/Stop/С начала, с выделенного места, повтор выделенного фрагмента, скорость 25–200 %, метроном.
* Микшер: громкость, выключение и соло для каждой руки, для мелодии и для сопровождения; реверберация.
* Встроенный банк GeneralUser GS (SF2), загрузка любого другого .sf2; вывод на внешнее MIDI-устройство.
* Воспроизводится то, что записано: повторы, вольты, переходы, ферматы, темпы, динамика, вилки, артикуляция,
  форшлаги, орнаменты, педаль, лиги.
* Подсветка звучащих нот и курсор, синхронные с партитурой; экспорт в MIDI и WAV (тем же синтезатором).

### Печать и экспорт
* PDF (векторный), печать через системный диалог, предварительный просмотр с настройками: формат, ориентация,
  поля, число тактов в системе, расстояния между станами и системами, размер стана, заголовок и номера страниц.
* MusicXML 4.0: экспорт и импорт (.musicxml, .xml, сжатый .mxl).

### Проекты и длинные произведения
* Формат `.nfg`: все ноты, голоса, ключи, размеры, тональности, темпы, разметка страниц, метаданные,
  мелодические линии, части и закладки. При открытии файл проверяется и, где можно, восстанавливается.
* Атомарная запись, резервная копия `имя.nfg.bak`, недавние файлы, открытие .nfg двойным щелчком.
* Автосохранение (по умолчанию каждые 2 мин); после аварийного завершения при следующем запуске
  предлагается восстановить работу.
* Части/разделы (с новой страницы или нет), буквы-ориентиры, закладки, навигатор, переход к такту (Ctrl+G).
* Быстрая частичная перерисовка: после правки нот видимая страница перерисовывается отдельно,
  полная раскладка идёт в фоне.

### Инструменты
* Экранная клавиатура (F11), ввод с MIDI-клавиатуры (аккорды — одновременным нажатием).
* Настраиваемые горячие клавиши (сохраняются), сетка ввода мышью (1/4…1/32).
* Статистика произведения, проверка тактов (незаполненные/переполненные, неполные группы,
  «висячие» лиги, выход за диапазон фортепиано, пустые такты) с автоисправлением.

## Ввод нот — кратко

**N** — режим ввода; **1–7** — длительность (1/64 … целая), **.** — точка; **A–G** — нота, **Shift+A–G** — в аккорд;
**0** — пауза; **+** — залигованная нота; **↑/↓**, **Ctrl+↑/↓** — полутон/октава; **Ctrl+Alt+1…4** — голос;
**Ctrl+3/5/6/7** — ритмические группы; **S** — лига; **Shift+,** / **Shift+.** — вилки; **/** — форшлаг;
**Shift+S/N/V/O** — стаккато/тенуто/акцент/маркато; **M** — в мелодию; **Space** — воспроизведение.
Мышью в режиме ввода: щелчок по стану ставит ноту, Shift+щелчок добавляет в аккорд.
Вне режима ввода: щелчок — нота, Shift+щелчок — фрагмент «от ноты до ноты», щелчок по пустому месту — такт.
Полный список — F1, переназначение — «Инструменты → Настроить горячие клавиши».

## Что проверено

* `npm test` — 48 модульных тестов: модель и ввод, файлы .nfg, MEI/Verovio без предупреждений, исполнение
  (тайминг, лиги, повторы, вольты, D.C./D.S., ферматы, педаль, динамика, трель), MIDI, SoundFont,
  MusicXML (полный цикл «экспорт → импорт» и одинаковое воспроизведение), проверка тактов, быстрая раскладка.
* Сценарии в реальном окне Electron (Playwright, Linux + Xvfb):
  * ввод и правка нот; аккорды, триоли, лиги через руки, межстановые ноты, мелодическая линия;
  * сохранение и повторное открытие;
  * воспроизведение с подсветкой нот; экспорт MIDI и WAV (проверен уровень сигнала);
  * PDF: 8 векторных страниц, текст извлекается; предпросмотр;
  * экспорт и импорт MusicXML;
  * восстановление после принудительного завершения процесса (SIGKILL); чистый выход удаляет автокопии;
  * навигатор и закладки; переназначение клавиши, которое сохраняется между запусками;
  * экранная клавиатура; сетка ввода 1/16; партитура на 1500 тактов.
* Упакованная сборка (asar, протокол `app://`) открывается, сохраняет и играет звук из встроенного банка.
* `npm run dist` собирает `NoteForge-Setup-1.0.0.exe` (на Linux через Wine).

### Что не проверялось

* Установщик **не запускался на реальной Windows**.
* Печать через системный диалог не проверялась автоматически: нужен принтер или дисплей.
  Используется тот же макет страниц, что и для проверенного PDF.
* MIDI-клавиатура и внешний MIDI-выход не проверялись с реальным устройством.
* Звук на слух не оценивался: проверялись сигнал WAV и работа синтезатора.

## Ограничения (честно)

* **Синтезатор.** Упрощённое воспроизведение SF2: огибающая громкости, петли, фильтр, панорама,
  реверберация. Модуляторы, кроме кривой скорости нажатия, LFO, огибающая модуляции и хорус не реализованы.
* **Ключи.** Смена ключа возможна только с начала такта.
* **Ритмические группы.** Не пересекают тактовую черту, вложенные группы не поддерживаются.
* **Динамика.** Действует на всю партию (обе руки).
* **Скорость раскладки.** На 1500 тактах (63 страницы):
  * правка нот видна через ~0.3–0.5 с;
  * полная раскладка занимает ~2–2.5 с, она идёт в фоновом потоке, интерфейс не блокируется;
  * изменение размера, ключа, тональности, числа тактов или линий ждёт полной раскладки;
  * вид «Лента» для очень длинных пьес рисуется одной большой картинкой и работает медленнее.
* **MusicXML.**
  * Не поддерживаются тексты песен, аккордовые обозначения, аппликатура, ударные.
  * Мелодические линии передаются через цвет нот.
  * Совместимость с файлами MuseScore/Sibelius/Finale проверена только на образце в стиле MuseScore.
  * Затакт импортируется как такт со своим размером.
