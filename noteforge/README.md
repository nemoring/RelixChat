# NoteForge — редактор фортепианных партитур

Настольное приложение для Windows (Electron + TypeScript + React) для сочинения и
редактирования нотных партитур. Гравировка — [Verovio](https://www.verovio.org)
(WebAssembly, работает локально, без интернета).

> **Статус: этап 1 из 5 — рабочий фундамент.** Ниже точно перечислено, что уже
> работает и что ещё не реализовано.

## Требования

* Node.js 20+ (проверено на 22) и npm
* Windows 10/11 x64 для запуска установщика (разработка возможна и на Linux/macOS)

## Команды

```bash
npm install      # зависимости
npm run dev      # запуск в режиме разработки (Vite + Electron, горячая перезагрузка интерфейса)
npm run build    # проверка типов + сборка интерфейса (dist/) и main/preload (dist-electron/)
npm run dist     # build + установщик Windows: release/NoteForge-Setup-<версия>.exe
npm test         # модульные тесты (модель, файлы, гравировка через Verovio)
npm start        # запуск уже собранного приложения
```

`npm run dist` на Windows работает без дополнительных программ. При сборке Windows-установщика
на Linux electron-builder требует Wine (32- и 64-битный).

## Что работает (этап 1)

**Нотный лист**

* Настоящие страницы A4/A3/Letter (книжная/альбомная), гравировка Verovio, векторный SVG.
* Постраничный вид и непрерывный вид «Лента», масштаб 25–400 % (Ctrl+колесо, Ctrl+= / Ctrl+-).
* Заголовок, подзаголовок, композитор, аранжировщик, обозначение темпа и метроном, номера страниц.
* Автоматическая разбивка на системы и страницы; виртуализация страниц (рисуются только видимые).

**Редактирование**

* Два нотоносца фортепиано (скрипичный/басовый, ключ можно сменить: альтовый, теноровый, 8vb).
* Ноты и паузы от целой до 1/64, точка, диезы/бемоли/бекары/дубль-альтерации.
* Аккорды; до 4 независимых голосов на каждом нотоносце.
* Лиги-связки (в т. ч. автоматические при переходе ноты через тактовую черту).
* Автоматические ребра по долям размера; знаки альтерации печатаются по правилам
  (действуют до конца такта, учитывают тональность).
* Размеры 2/4, 3/4, 4/4, C, ¢, 5/4, 3/8, 6/8, 7/8, 9/8, 12/8 и произвольные; смена размера
  в середине произведения с автоматической перегруппировкой музыки.
* Тональности от 7♭ до 7♯, смена с любого такта.
* Добавление, вставка и удаление тактов; очистка, копирование, вырезание и вставка диапазона тактов.
* Транспонирование выделения на полутон / октаву.
* Отмена/повтор (до 500 шагов).

**Проекты**

* Собственный формат `.nfg` (JSON): все ноты, голоса, размеры, тональности, ключи, темп,
  разметка страницы, метаданные. После повторного открытия данные восстанавливаются полностью
  (проверено автоматическим тестом).
* Проверка файла при открытии, автоматическое исправление восстановимых ошибок с отчётом.
* Атомарная запись и резервная копия предыдущей версии (`имя.nfg.bak`).
* Предупреждение о несохранённых изменениях при закрытии окна; открытие `.nfg` двойным щелчком
  (ассоциация файлов в установщике).

**Инструменты**: статистика произведения (такты, ноты, длительность, диапазон по рукам),
переход к такту, справочник горячих клавиш (F1).

## Как вводить ноты

1. Нажмите **N** (или кнопку «Ввод») — появится курсор ввода.
2. Длительность: **1**–**7** (1/64 … целая), **.** — точка.
3. Ноты: **A–G** (октава выбирается ближайшая к предыдущей ноте), **Shift+A–G** — добавить
   ноту в аккорд, **0** — пауза, **+** — залигованное повторение ноты.
4. **↑/↓** — полутон, **Ctrl+↑/↓** — октава, кнопки ♯ ♭ ♮ 𝄪 𝄫 на панели — альтерация.
5. **Ctrl+Alt+1…4** — голос, **Ctrl+Alt+↑/↓** — перейти на другой нотоносец.
6. Мышью в режиме ввода: щелчок по нотоносцу ставит ноту на эту высоту и долю,
   Shift+щелчок добавляет её в аккорд.
7. **Esc** — выход в режим выделения. Щелчок по ноте выделяет её, по пустому месту такта —
   такт, Shift+щелчок — диапазон тактов.

Клавиши работают и в русской раскладке (используются физические клавиши).

## Проверка

Что реально выполнялось при разработке этапа 1:

* `npm test` — 17 тестов (vitest): арифметика длительностей, ввод с перезаписью, лиги через
  такт, аккорды, голоса, вставка/удаление тактов, смена размера, копирование/вставка,
  сохранение/открытие `.nfg`, восстановление повреждённого файла, генерация MEI и раскладка
  Verovio без ошибок (включая партитуру на 400 тактов).
* Сценарии в настоящем окне Electron (Playwright, Linux + Xvfb): ввод нот с клавиатуры и мышью,
  аккорд, лига, выделение щелчком, транспонирование, undo/redo, изменение длительности,
  копирование такта, сохранение → новая партитура → открытие (модель совпала побайтно),
  создание `.bak`, палитра тональностей и размеров, непрерывный вид, масштаб. Тот же сценарий
  прогнан на упакованной сборке (asar, протокол `app://`).
* `npm run dist` собрал `NoteForge-Setup-0.1.0.exe` (на Linux через Wine). **Установщик на
  реальной Windows не запускался** — это нужно проверить вручную.
