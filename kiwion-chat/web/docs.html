Kiwion Developer API

OpenAI-совместимый API модели OLMo 2 1B Instruct · Kiwion Chat · OpenAPI

Быстрый старт

  1. Войдите в Kiwion Chat и подтвердите email.
  2. Откройте Настройки → API-ключи и создайте ключ. Полное значение (kw-…) показывается только один раз — сервер хранит лишь его хеш.
  3. Передавайте ключ в заголовке Authorization: Bearer kw-….

Базовый URL: https://your-domain/v1. Модель: olmo-2-1b-instruct.

Эндпоинты

МетодПутьОписание
GET/v1/modelsСписок моделей
POST/v1/chat/completionsГенерация ответа (в том числе потоковая, "stream": true)

Примеры

cURL

curl https://your-domain/v1/chat/completions \
  -H "Authorization: Bearer $KIWION_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "olmo-2-1b-instruct",
    "messages": [{"role": "user", "content": "Расскажи про птицу киви"}],
    "max_tokens": 200
  }'

# потоковый ответ
curl -N https://your-domain/v1/chat/completions \
  -H "Authorization: Bearer $KIWION_API_KEY" -H "Content-Type: application/json" \
  -d '{"model":"olmo-2-1b-instruct","stream":true,"messages":[{"role":"user","content":"Привет!"}]}'

Python (официальный SDK openai)

from openai import OpenAI

client = OpenAI(base_url="https://your-domain/v1", api_key="kw-...")

# обычный ответ
r = client.chat.completions.create(
    model="olmo-2-1b-instruct",
    messages=[{"role": "user", "content": "Напиши хайку про киви"}],
)
print(r.choices[0].message.content, r.usage)

# потоковый ответ
stream = client.chat.completions.create(
    model="olmo-2-1b-instruct",
    messages=[{"role": "user", "content": "Объясни рекурсию"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

Python (без SDK, httpx)

import httpx, json

with httpx.stream("POST", "https://your-domain/v1/chat/completions",
                  headers={"Authorization": "Bearer kw-..."},
                  json={"model": "olmo-2-1b-instruct", "stream": True,
                        "messages": [{"role": "user", "content": "Привет"}]},
                  timeout=300) as r:
    for line in r.iter_lines():
        if line.startswith("data: ") and line != "data: [DONE]":
            delta = json.loads(line[6:])["choices"][0]["delta"]
            print(delta.get("content", ""), end="", flush=True)

JavaScript (fetch, Node 18+ и браузер)

const res = await fetch("https://your-domain/v1/chat/completions", {
  method: "POST",
  headers: { "Authorization": `Bearer ${process.env.KIWION_API_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "olmo-2-1b-instruct",
    stream: true,
    messages: [{ role: "user", content: "Как дела, киви?" }],
  }),
});
const reader = res.body.getReader();
const decoder = new TextDecoder();
let buffer = "";
for (;;) {
  const { value, done } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split("\n");
  buffer = lines.pop();
  for (const line of lines) {
    if (!line.startsWith("data: ") || line === "data: [DONE]") continue;
    const delta = JSON.parse(line.slice(6)).choices[0]?.delta?.content;
    if (delta) process.stdout.write(delta);
  }
}

Лимиты

У каждого ключа есть лимит запросов в минуту и дневной лимит токенов (значения видны в настройках, администратор может их изменить). При превышении возвращается 429 с rate_limit_exceeded или insufficient_quota и заголовком Retry-After.

Если модель перегружена, ответ — 503 с кодом overloaded: повторите запрос позже с экспоненциальной задержкой.

Ошибки

HTTPcodeЗначение
400invalid_requestНекорректный запрос
401invalid_api_keyКлюч не найден или отозван
403account_disabledАккаунт заблокирован или не подтверждён
404model_not_foundНеизвестная модель
429rate_limit_exceeded, insufficient_quotaПревышен лимит
503overloaded, model_unavailableМодель занята или недоступна

Формат ошибки: {"error": {"message": "...", "type": "...", "code": "..."}}.

Учёт токенов

Каждый ответ содержит usage с реальным числом токенов, посчитанным llama.cpp. Статистика по дням — в настройках (вкладка «API-ключи»).
