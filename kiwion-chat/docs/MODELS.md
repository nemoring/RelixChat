# Модели

Kiwion работает с любой чат-моделью в формате **GGUF**, которую поддерживает llama.cpp:
OLMo 2, Gemma 3, Qwen3, Llama 3.2 и др. Модель меняется заменой файла, код трогать не нужно.

- **Шаблон диалога** берётся из самой модели (метаданные GGUF, `/apply-template` llama.cpp).
  Для OLMo используется собственный точный шаблон Kiwion. Управляется `KIWION_PROMPT_FORMAT=auto|olmo2|model`.
- **Название и ID** для приложений и Developer API определяются по имени файла
  (`gemma-3-4b-it-Q4_K_M.gguf` → «Gemma 3 4B», `gemma-3-4b`) или задаются через `KIWION_MODEL_NAME`, `KIWION_MODEL_ID`.
  В API всегда можно писать `"model": "kiwion"` — это «текущая модель сервера».

## Что подходит под VPS 4 ГБ RAM / 2 vCPU

| Модель | Файл (Q4_K_M) | RAM | Русский | Лицензия |
|---|---|---|---|---|
| OLMo 2 1B Instruct | ~0,9 ГБ | ~1,3 ГБ | слабый | Apache 2.0 |
| **Gemma 3 4B (it)** | ~2,5 ГБ | ~3 ГБ | хороший | Gemma Terms of Use |
| Qwen3 4B | ~2,5 ГБ | ~3 ГБ | хороший | Apache 2.0 |
| Qwen3 1.7B | ~1,1 ГБ | ~1,5 ГБ | средний | Apache 2.0 |

Размеры приблизительные; скорость измерьте на своём сервере (`kiwion benchmark`).
Для 7–8B моделей нужен VPS с 8 ГБ RAM.

## Где взять файл

На Hugging Face, готовые GGUF, например:
- Gemma 3 4B: репозитории `bartowski/google_gemma-3-4b-it-GGUF` или `unsloth/gemma-3-4b-it-GGUF`,
  файл `…gemma-3-4b-it-Q4_K_M.gguf`. Используя Gemma, вы принимаете условия Gemma Terms of Use (Google).
- Qwen3 4B: `Qwen/Qwen3-4B-GGUF` (Q4_K_M).

Нужен только основной файл модели. Файл `mmproj` (для картинок) не нужен.

## Как поменять модель на сервере (офлайн-установка)

1. Положите `.gguf` в папку `models/` рядом с `install.sh` из офлайн-архива.
2. Запустите `sudo WITH_MODEL=1 bash install.sh <домен> <email>` — установщик возьмёт новую модель
   (данные, пользователи и настройки сохраняются).

Или вручную: скопируйте файл в `/opt/kiwion-app/models/`, впишите путь в `KIWION_MODEL_PATH`
в `/opt/kiwion-app/.env` и выполните `systemctl restart kiwion-inference`.

Для длинных ответов увеличьте `KIWION_CTX` (Gemma 3 и Qwen3 поддерживают 4096 и больше) и
`KIWION_MAX_TOKENS_CAP`, затем «Макс. токенов в ответе» в админке.

## Сборка llama.cpp на VPS

Офлайн-установщик собирает **переносимую** версию llama.cpp (`GGML_CPU_ALL_VARIANTS`): код для всех
поколений x86-процессоров, нужный вариант выбирается при запуске. Если хостинг перенесёт VPS на сервер
с другим процессором, модель продолжит работать. При каждой установке сборка проверяется на маленькой
тестовой модели; если она не запускается на текущем процессоре, установщик пересоберёт её сам.
