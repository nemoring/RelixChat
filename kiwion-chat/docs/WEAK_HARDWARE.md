# Запуск на слабом железе: Intel Pentium 4417U, 8 ГБ RAM, Intel HD 620

## Что за процессор

Pentium Gold 4417U (Kaby Lake): 2 ядра / 4 потока, 2,3 ГГц, **SSE4.1/4.2, без AVX/AVX2**, DDR4.
llama.cpp работает и без AVX, но медленнее, поэтому важны квантизация и правильные потоки.

## Рекомендуемые настройки (`.env` на узле)

```ini
KIWION_THREADS=2          # число физических ядер; гиперпотоки только мешают
KIWION_CTX=2048           # контекст на один слот
KIWION_PARALLEL=1         # одна генерация за раз, остальные — в очереди
KIWION_MAX_QUEUE=6
KIWION_BATCH=256
KIWION_KV_CACHE_TYPE=f16  # q8_0 — вдвое меньше памяти KV-кэша (включает flash attention)
KIWION_MODEL_PATH=models/olmo-2-1b-instruct-Q4_K_M.gguf
```

- **Собирайте llama.cpp на этой же машине** (`scripts/build_llamacpp.sh`, `GGML_NATIVE=ON`): бинарник,
  собранный на машине с AVX2, упадёт на Pentium с «Illegal instruction».
- `JOBS=2 scripts/build_llamacpp.sh` — чтобы компиляция не съела всю память.

## Память (оценка)

| Компонент | Q4_K_M | Q8_0 |
|---|---|---|
| Веса OLMo 2 1B (≈1,5 млрд параметров) | ≈ 0,9 ГБ | ≈ 1,6 ГБ |
| KV-кэш, 2048 токенов, f16 (16 слоёв × 2048 × 2 × 2 Б) | ≈ 0,27 ГБ | ≈ 0,27 ГБ |
| KV-кэш с `KIWION_KV_CACHE_TYPE=q8_0` | ≈ 0,14 ГБ | ≈ 0,14 ГБ |
| Kiwion Inference (Python) | ≈ 0,08 ГБ | ≈ 0,08 ГБ |
| **Итого** | **≈ 1,3 ГБ** | **≈ 2,0 ГБ** |

В 8 ГБ остаётся много места для системы и браузера. Веса подгружаются через mmap, поэтому стартовая
загрузка быстрая, а неиспользуемые страницы система может вытеснить. `KIWION_MLOCK=1` фиксирует веса в
RAM (быстрее после простоя, но память не освобождается).

## Скорость (оценка — измерьте сами)

Без AVX ориентир для Q4_K_M: генерация порядка **3–6 токенов/с**, обработка промпта — десятки токенов
в секунду; ответ на 200 токенов — около минуты. Это **оценка**, на реальном Pentium 4417U не
измерялась (в окружении разработки его не было). Измерить:

```bash
kiwion benchmark                 # TTFT и ток/с через сервис
kiwion benchmark --llama-bench   # llama-bench напрямую по GGUF
```

Чтобы ответы приходили быстрее: уменьшите «Макс. токенов в ответе» в админке (например, 256), держите
`KIWION_PARALLEL=1`. Клиенты рассчитаны на медленную модель: показывают позицию в очереди, «киви печатает»,
подсказку после 15 с ожидания, таймаут чтения потока — 5 минут.

## Intel HD 620 (Vulkan) — экспериментально

```bash
sudo apt install libvulkan-dev glslc mesa-vulkan-drivers
KIWION_VULKAN=1 scripts/build_llamacpp.sh
KIWION_GPU_LAYERS=99 kiwion server start
kiwion benchmark
```

Встроенная графика делит память и пропускную способность с CPU; для модели 1B выигрыш не гарантирован
(иногда медленнее CPU). Сравните `kiwion benchmark` с `KIWION_GPU_LAYERS=0` и `99` и оставьте лучший.

## Нагрузка на систему

systemd-юнит запускает инференс с `Nice=5` и `CPUWeight=80`, чтобы компьютером можно было пользоваться
во время генерации; `MemoryMax=3G` защищает систему от нехватки памяти. Если llama-server падает,
Kiwion Inference перезапускает его автоматически.
